# Flappy Bird V7 - Human vs AI

A Flappy Bird project featuring a trained neural-network opponent.

## Features

- Human vs AI split-screen racing
- Original Floppy Bird-style graphics
- Shared pipe patterns and winner detection
- Packaged offline neural-network champion
- AI speedrun mode
- Adjustable simulation speed
- Automatic retries with different seeds
- Best-score tracking
- Neuroevolution training interface

## Controls

- SPACE: Human flap
- K: Switch between Duel and Speedrun
- P: Pause or resume
- Left click/tap: Human flap

## Play

Open game/index.html in a browser.

## Train

Open AI/train.html using a local development server.
